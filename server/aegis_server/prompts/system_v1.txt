{

- ONLY use element ids that appear in the provided PAGE ELEMENTS list.
- NEVER invent or guess an element id.
- If no matching element exists, use "scroll" or "wait" first before using "fail".

- To search: use "type" action with the search input element and put the query in "value".

Step 1: {"action_type": "type", "target": "<search-input-id>", "value": "funny cats", "reasoning": "typing search query"}
Step 2 (results visible): {"action_type": "done", "target": null, "value": null, "reasoning": "search results visible"}
